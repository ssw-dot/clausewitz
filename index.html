Clausewitz

Small organisations lose weeks writing applications they were never eligible for. Clausewitz reads open calls against what you actually are, and quotes the clause that disqualifies you.

This page is not a re-implementation. It fetches clausewitz/screening.py, normalise.py and report.py from this repository and runs them in your browser under CPython. If the code changes, this demo changes with it. Nothing is sent anywhere — the screening layer has no network calls and needs no credentials, which is exactly why it can run here at all.

The bundled calls are real. Their wording is quoted from their own rules — three of them are hackathons we read while looking for funding for this project, and the reason we built the tool.

Why the quote, and not just the answer

A tool that says no without showing why has to be trusted completely or not at all — and nobody should trust this completely. It is reading legal-ish prose with a language model. Handing you the sentence changes what it is: it stops being an oracle and becomes a reader that points. When it is right you saved six hours; when it is wrong you notice at once, because the evidence came attached.

So there are three buckets, never two. A call that says nothing about who may enter is not a call that admits everyone — it is a call a person has to read. Every ambiguity fails towards needs a human, never towards not eligible:

  • a quote not found in the source text
  • a rule this screener has no check for
  • a place named that cannot be resolved to a country
  • nothing extracted at all

Wrongly telling someone not to apply costs them a grant. Wrongly asking a human to look costs them a minute.

The model reads. The code decides.

A Strands agent is given one job: report each demand a call makes on who may enter, quoting the sentence it came from. It has one tool, report_requirement, and no vocabulary for a verdict. Then ordinary Python — the module running on this page — decides.

What enforces the split is a function, not a prompt. Every requirement must quote text that appears verbatim in the source. A requirement the model invented quotes nothing that exists, fails the check, and is dropped before any rule sees it. A hallucination cannot become a rejection. That is the button marked verify every quote, and it is the same code that runs in CI.

Reading a new call needs the model, so it lives in the command line only:

pip install "strands-agents[litellm]"
export GOOGLE_API_KEY=...
python -m clausewitz --read path/to/rules.txt
